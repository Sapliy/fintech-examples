# Sapliy Fintech Examples

This repository contains real-world integration examples for the Sapliy Fintech Ecosystem.

## Examples List

- **[Node.js](node/)**: Express.js server using `@sapliyio/fintech`.
- **[Python](python/)**: FastAPI server using `sapliyio_fintech`.
- **[Go](go/)**: Net/HTTP server using `github.com/sapliy/fintech-sdk-go`.
- **[React](react-app/)**: Web frontend using `@sapliyio/fintech-ui`.
